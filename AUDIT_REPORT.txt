CHANGES
1. Implementation XDC selects clock families with -include_generated_clocks
   from clk_pl_0, GMX_A_CLK0 and GMX_A_CLK1. The previous literal name
   gmax_a_pixel_clk did not exist; the /5 clock was named u_training_n_1.
   The inverted /4 descendants are now included as well. /4 and /5 from CLK0
   remain related; their waveforms, dividers and common reset are unchanged.
2. Narrow first-stage timing exceptions cover the existing lane control
   synchronizers only. Later stages remain timed. The IDELAY bus and load
   event have per-lane skew bounds to preserve the existing delayed capture.
3. The existing custom asynchronous FIFO RAM data transfer has a 6.668 ns
   datapath bound for the same-family /4-to-/5 crossing. This avoids requiring
   new RAM data at the next unrelated phase edge: the read enable is gated by
   the synchronized Gray write pointer and empty flag. Read-address paths and
   ordinary read-domain logic remain timed. Cross-family paths retain the
   existing asynchronous-clock-family intent.
4. Add 6.668 ns skew bounds for each of the 32 six-bit FIFO Gray pointer
   crossings. XPM_CDC_ARRAY_SINGLE supplies a false path, not a Gray-bus skew
   bound. The pointer MSB is optimized into the corresponding binary MSB;
   the constraints explicitly include that actual source register.
5. Correct a stale clock-name comment in the main XDC. Preserve primary
   clocks, I/O timing exceptions, pinout, electrical settings and PCIe rules.
6. Add REBUILD_V16_3.tcl and endpoint checks. Rebuilds disable incremental reuse,
   verify XPM identity after synthesis and routing, and create new timestamped
   timing RPX/text, CDC, skew, clock, methodology, DRC and checkpoint outputs.

LIMITS OF SIGN-OFF
The original full CDC report has 40 critical findings: 18 CDC-13, 2 CDC-1,
12 CDC-10 and 8 CDC-11. These are distinct from the resolved freeze issue.
They include trained serial inputs, raw I2C ILA sampling, the combinational
diagnostic readback mux, and replicated bit-width synchronizers. No blanket
waivers have been added. See the new full CDC report for final counts.
The selector protocol waits 10 us after changing index/lane; firmware waits
20 ms after requesting freeze. Those software delays are not a hardware
acknowledgement or a proof of bus coherence under arbitrary clock stoppage.
The FIFO supports coordinated reset/flush; independent mid-stream reset of
one pointer is not validated by static timing. Preserve the established reset
sequence. Gray pointer reset is not a normal one-bit increment.
The 16 serial inputs remain intentionally false-pathed for IDELAY training;
static timing therefore does not certify board-level serial-eye margin.
No board was programmed or exercised. Training, D0/D1 diagnostic readout,
I2C and other validated board functions still require hardware regression.
Frame/line-valid remain tied low, as in the original bring-up scope.
